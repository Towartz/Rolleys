# Rolleys

High-performance Rust-based client engine for multi-platform WhatsApp applications.

> [!NOTE]
> Active core development and production releases have transitioned to a private repository.

### Highlights
- Multi-platform FFI bindings (Android Kotlin UniFFI, Desktop, Web)
- Pure native Signal protocol encryption & end-to-end security
- Modern async architecture powered by Tokio
- Multi-device state synchronization and media pipelines
